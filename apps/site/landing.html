本地优先 · 开源 MIT

默默 Momoki

每部片子，都从一粒光点开始。

本地优先的 AI 创作工作室，让故事、画面、声音和音乐在同一个项目中逐步成形。

  • 视频、音频与音乐，三类项目同在一个应用里

画面：黑场里亮起一粒光点，汇聚成片名。

在浏览器中体验下载桌面版GitHub

第一幕 · 灵感 → 剧本

从一个念头开始

先有一个念头，然后是一行字。

先把故事想清楚：世界设定、剧本与场次，都收在同一个项目里。

  • 单片与剧集两种组织方式，剧集可在多集之间共享项目设定与资产
  • 参考资料（图片、TXT/Markdown、文本 PDF、DOCX）在本机解析；选中的内容会随 AI 请求发给你所选的供应商
  • 多个 IP 档案与三级素材库；项目采用素材时创建副本并记录版本

画面：散落的光点排成剧本的文字行，逐字显现。

第二幕 · 剧本 → 分镜

文字变成镜头

文字落成镜头，一格，一格。

把场次落到具体镜头：顺序、时长、提示词，以及与角色、场景、道具的关联。

  • 镜头表可筛选、拖拽排序，并支持快捷操作
  • 画面通过助手中的生成流程制作：供应商、模型与提示词由你确认，候选结果由你检查后采用

画面：文字行裂变为分镜格，镜头编号与时间码依次生成。

第三幕 · 创作助手

一位安静的助手

有个安静的帮手，你点头，它才动手。

围绕你绑定的项目对话、制定任务计划、调用已启用的工具，并留下可回看的执行记录。

  • 三档权限：请求批准、帮我批准、完全访问
  • 执行记录展示工具调用与实际写入的结果；模型说“完成”，不替代工作台里真正保存的内容
  • 项目记忆可手动维护，让后续创作沿用约定与偏好

示意：安静的对话与工具时间线，并非真实界面截图。

第四幕 · 本机优先

数据留在你这里

作品留在你这里，钥匙也是。

桌面版存入本机 SQLite 与受管理的文件，浏览器版存入当前站点来源的 IndexedDB，不需要服务端应用数据库。

  • AI 使用你自己的服务与 API Key，请求直接发往你配置的供应商；默默本身不提供模型服务
  • “本地优先”不等于全部离线：AI 与联网研究需要联网，浏览器存储也不是系统钥匙串
  • 浏览器版与桌面版的数据相互独立，目前不会自动同步

画面：胶片盒缓缓合上，项目留在这台设备里。

第五幕 · 成片与交付

把成果交出去

想带走，就整整齐齐地交出去。

先检查资料与媒体的缺口，再导出可以移交、也可以备份的文件。

  • 当前集的分镜 CSV、可打印分镜板与制作素材交付 ZIP
  • 项目 ZIP 用于备份与迁移，可重新导入；它不含 API Key，也不是整个工作室的镜像
  • 目前不含完整的视频时间线剪辑与转场合成，交付的是镜头与素材

画面：胶片条依次折成 ZIP、CSV 与分镜板。

常见问题

我的数据存在哪里？

桌面版存入本机 SQLite 与受管理的文件；浏览器版存入当前站点来源的 IndexedDB。换浏览器、无痕窗口、清理站点数据或更换域名，都可能看不到原来的项目，请定期导出项目 ZIP。

需要联网或自带 API Key 吗？

不使用 AI 时无需 API Key，可以本地编辑项目、管理素材并导出。AI 对话、生成和联网研究需要你自备服务的 API Key，并需要联网；部分供应商可能因跨域限制无法在浏览器里直连。

桌面版和网页版有什么区别？

两者共用同一套界面与业务逻辑。桌面版使用原生 HTTP 传输，可以避开浏览器的跨域限制；两者的数据相互独立，目前不会自动同步。

收费吗？用什么协议？

应用本身开源，采用 MIT 协议。默默不提供模型服务，模型调用的额度与费用由你所选的供应商决定。

安装包为什么没有签名？

桌面版目前是测试版：Windows 安装包未签名，macOS 应用未经公证，首次打开可能出现系统安全提示。请只从 GitHub Releases 下载，并可用 SHA256 校验值核对安装包。

项目数据只保存在你的浏览器或本机，不会上传到默默的服务器；AI 请求直接发往你配置的供应商。浏览器版与桌面版的数据相互独立，请定期导出项目 ZIP。本页会加载 Google Fonts，站点可能启用 Umami 访问统计。
