# 安装指南配图

两张图是 Momoki 文档制作的**操作示意，不是操作系统截图**。用于解释首次安装时可能出现的身份与信誉提示；不表示任何设备上的实际弹窗结果，也不代表 Apple 或 Microsoft 的认证。

| 图 | 用途 |
| --- | --- |
| [windows-first-open.png](windows-first-open.png) | GitHub Markdown 配图：更多信息 → 核对文件名与来源 → 自愿继续时仍要运行 |
| [macos-first-open.png](macos-first-open.png) | GitHub Markdown 配图：先尝试打开 → 隐私与安全性 → 自愿继续时仍要打开 |

PNG 尺寸为 1600 × 1040。对应的 SVG 是可编辑原稿，中文字体使用黑体类回退。文档引用 PNG，避免读者的字体环境影响图中文字。

图中 `<版本号>` 是通用占位文字；实际安装包文件名中没有尖括号。macOS 左侧复用了现有 Momoki 应用图标，未重绘品牌；正式品牌素材以 [public/brand](../../../public/brand/README.md) 为准。

按钮名称、位置与提示内容会随系统版本变化。后续替换成真实截图时，请使用公开发布版本，在干净测试设备上记录实际流程，隐藏私人信息，并同步更新图注。不要把示意图描述成该版本已通过安装或安全验证的证据。

流程依据：[Apple 官方说明](https://support.apple.com/zh-cn/102445)、[Microsoft SmartScreen 说明](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation)。
